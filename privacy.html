본 방침은 RESONARA Uploader(이하 '도구')가 Google 및 YouTube 사용자 데이터를 어떻게 접근·이용·보관·공유하는지를 설명합니다. 도구는 RESONARA YouTube 채널 운영자의 자체 콘텐츠 업로드 자동화를 위한 것입니다.

1. 접근하는 데이터와 권한

도구는 운영자가 승인한 YouTube API 권한(youtube.upload, youtube.readonly)을 통해 동영상 업로드와 채널 확인에 필요한 정보에 접근합니다. Google 계정 비밀번호를 직접 수집하지 않습니다.

2. 이용 목적

채널 식별·확인, 운영자가 준비한 영상의 YouTube 업로드, 업로드 처리 상태 및 오류 확인에만 Google·YouTube 데이터를 사용합니다. 이와 무관한 광고 타게팅이나 데이터 판매 목적으로 사용하지 않습니다.

3. 보관 및 보호

자동 업로드를 유지하는 데 필요한 OAuth 인증 정보는 운영자가 관리하는 Google Cloud 환경의 비밀정보 저장소 등을 통해 보관될 수 있습니다. 기술적 접근 제한을 적용하여 보호하며, 서비스 운영에 필요한 기간만 보관하고 권한 철회 또는 운영 종료 시 삭제합니다.

4. 제3자 공유

Google·YouTube API 제공과 운영에 필요한 통신을 제외하고, Google 사용자 데이터를 광고주나 데이터 중개업자에게 판매하거나 제공하지 않습니다. 호스팅·클라우드 서비스를 통한 처리에는 해당 서비스의 정책이 적용될 수 있습니다.

5. 접근 철회 및 삭제 요청

운영자는 Google 계정의 연결된 앱 및 서비스에서 접근 권한을 철회할 수 있습니다. 데이터 삭제 및 문의는 아래 연락처로 요청할 수 있습니다.
